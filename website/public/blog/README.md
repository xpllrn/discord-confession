# Blog images

Drop blog images in this folder. They're served from the site root under `/blog/...`.

Images referenced by the "How to Protect Your Discord Server from Nukes and Raids" post:

- `discord-nuke-raid-protection.png` - cover / OG share image (recommended 1280×685 for social embeds)
- `discord-raid-example.png` - illustration of a raid
- `antinuke-overview.png` - screenshot of `,antinuke overview`
- `antiraid-overview.png` - screenshot of `,antiraid overview`

To use one inside the markdown post, add a line like:

```md
![adore antinuke overview](/blog/antinuke-overview.png)
```

(The post currently has these spots marked with `<!-- IMAGE: ... -->` comments -
replace each comment with the matching image line above.)

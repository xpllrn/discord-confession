1. Invite Confession

Use the official invite so Confession can post messages and register slash commands:

Open invite

Someone with Manage Server must authorize the bot.

2. Run /setup

Administrators should run /setup once after inviting:

  1. Select the channel(s) where confessions should appear.
  2. Optionally pick a private review channel for staff approval.
  3. Confirm — Confession is ready for /confess.

3. Submit a confession

Anyone in the server can run /confess. A modal asks for the text (and optional image). The post is anonymous — Discord usernames and avatars are never shown on the confession.

Each published confession includes buttons to confess again, reply in a thread, or report the post.

Review mode

If you configured a review channel during setup, new submissions go there first. Staff can approve or reject before anything is posted publicly.

Customization with /panel

Administrators can open /panel to:

  • Update the bot’s per-server display name, avatar, banner, and bio
  • Manage blocked words that should never appear in confessions

Safety notes

  • Follow Discord’s Terms of Service and your server rules.
  • Use Report on posts that violate community standards.
  • Enable review mode for communities that need extra moderation.
  • Author identities are stored only for abuse investigation by the bot operator — never shown in public posts.

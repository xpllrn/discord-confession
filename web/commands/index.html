Commands

Slash commands and confession buttons for members, admins, and the bot owner.

Everyone

/confess
Everyone
Open the confession modal. Optionally attach an image. Posts anonymously to your server’s confession channel (or review queue if enabled).
/help
Everyone
Show bot overview, available commands, and a link to the support server.
/ping
Everyone
Check whether Confession is online and see current WebSocket latency.
Report (button)
Everyone
On each confession post, use Report to flag content for staff. No slash command required.
Reply (button)
Everyone
Reply anonymously to a confession; creates or uses a discussion thread under that post.

Administrators

/setup
Administrator
Guided setup: choose confession channel(s), optional review channel, and finish server configuration.
/panel
Administrator
Customization panel — server profile (name, avatar, banner, bio) and blocked-word filter management.

Bot owner

/lookup
Owner
Look up who submitted a confession by guild ID and confession ID. Owner-only safety tool.
/confessionlogs
Owner
List recent confessions stored for a guild.
/replylogs
Owner
List recent anonymous replies stored in the database.
